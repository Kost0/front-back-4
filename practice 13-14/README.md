# Мои заметки — PWA

## Стек технологий

- **Frontend:** Vanilla JS, HTML, CSS3
- **Backend:** Node.js, Express, HTTPS 
- **Реалтайм:** Socket.IO (WebSocket)
- **Push-уведомления:** Web Push API + VAPID (`web-push`)
- **Офлайн:** Service Worker (App Shell + Cache API)
- **Хранение данных:** `localStorage`


## Реализованный функционал

### Занятие 13 — PWA-основы
- App Shell архитектура: мгновенная загрузка из кэша
- `manifest.json` с иконками, темой, `display: standalone`
- Установка приложения на устройство

### Занятие 14 — Service Worker и офлайн
- Кэширование статики (стратегия **Cache First**)
- Кэширование динамического контента (стратегия **Network First**)
- Корректная работа при отсутствии сети
- Очистка устаревших кэшей при активации SW

### Занятие 15 — HTTPS
- Запуск сервера по HTTPS на `localhost:3000`
- Самоподписанный сертификат (`mkcert` / `localhost.pem`)

### Занятие 16 — WebSocket + Push
- Реалтайм-уведомление при добавлении заметки через Socket.IO
- Подписка / отписка от Push-уведомлений (Web Push API, VAPID)
- Отправка push с сервера при создании новой задачи

### Занятие 17 — Детализация Push (напоминания)
- Форма для создания заметки с датой и временем напоминания (`datetime-local`)
- Заметки хранят поля `id` (уникальный timestamp), `reminder` (timestamp), `createdAt`
- Сервер планирует отправку push через `setTimeout` и хранит активные таймеры в `Map`
- Push-уведомление о напоминании содержит кнопку **«Отложить на 5 минут»**
- Service Worker обрабатывает `notificationclick` — действие `snooze` отправляет `POST /snooze` на сервер
- Эндпоинт `/snooze` отменяет прежний таймер и создаёт новый (+5 минут)
- Напоминания работают при закрытом браузере (пока жив процесс Node.js)


## Работа с приложением

1. **Добавить заметку** — заполнить поле «Заголовок» и нажать «Добавить заметку».
2. **Добавить напоминание** — заполнить текст и выбрать дату/время, нажать «Добавить с напоминанием». В указанное время придёт push-уведомление.
3. **Отложить напоминание** — нажать кнопку «Отложить на 5 минут» прямо в уведомлении.
4. **Включить push** — нажать кнопку «Включить уведомления» в футере и разрешить уведомления в браузере.


## API сервера

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/subscribe` | Сохранить push-подписку |
| `POST` | `/unsubscribe` | Удалить push-подписку |
| `POST` | `/snooze?reminderId=<id>` | Отложить напоминание на 5 минут |

### WebSocket события

| Событие | Направление | Описание |
|---------|-------------|----------|
| `newTask` | Client → Server | Новая заметка (без напоминания) |
| `newReminder` | Client → Server | Новая заметка с напоминанием |
| `taskAdded` | Server → Clients | Широковещательное уведомление о новой задаче |
