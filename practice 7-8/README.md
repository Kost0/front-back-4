
# Shop API — Практики 7 - 12:
 
Веб-приложение интернет-магазина с системой ролей.  
Бэкенд — Node.js + Express, фронтенд — React + Vite.
 

 
## Роли пользователей
 
| Роль | Описание |
|------|----------|
| **guest** | Неаутентифицированный пользователь. Может просматривать список товаров и регистрироваться |
| **user** | Покупатель. Просматривает товары, видит детальную карточку |
| **seller** | Продавец. Создаёт и редактирует товары |
| **admin** | Администратор. Всё, что умеет продавец + удаление товаров + управление пользователями |
 

 
## API — маршруты
 
### Аутентификация (доступно всем)
 
| Метод | Маршрут | Описание |
|-------|---------|----------|
| `POST` | `/api/auth/register` | Регистрация. Поля: `email`, `first_name`, `last_name`, `password`, `role` |
| `POST` | `/api/auth/login` | Вход. Возвращает `accessToken` (15 мин) и `refreshToken` (7 дней) |
| `POST` | `/api/auth/refresh` | Обновление пары токенов.|
| `GET`  | `/api/auth/me` | Данные текущего пользователя. Требует Bearer-токен |
 
### Пользователи (только admin)
 
| Метод | Маршрут | Описание |
|-------|---------|----------|
| `GET`    | `/api/users` | Список всех пользователей |
| `GET`    | `/api/users/:id` | Пользователь по id |
| `PUT`    | `/api/users/:id` | Обновить имя, фамилию или роль |
| `DELETE` | `/api/users/:id` | Заблокировать пользователя |
 
### Товары
 
| Метод | Маршрут | Доступ | Описание |
|-------|---------|--------|----------|
| `GET`    | `/api/products` | Все | Список товаров |
| `GET`    | `/api/products/:id` | user, seller, admin | Товар по id |
| `POST`   | `/api/products` | seller, admin | Создать товар |
| `PUT`    | `/api/products/:id` | seller, admin | Обновить товар |
| `DELETE` | `/api/products/:id` | admin | Удалить товар |
 

 
## Авторизация
 
Все защищённые маршруты принимают токен в заголовке:
 
```
Authorization: Bearer <accessToken>
```
 
При истечении access-токена клиент автоматически запрашивает новую пару через `/api/auth/refresh`.
 

 
## Middleware
 
**`authMiddleware`** — проверяет наличие и валидность Bearer-токена. При успехе кладёт payload в `req.user`.
 
**`roleMiddleware(roles)`** — проверяет, что роль пользователя из `req.user.role` входит в список `roles`. Иначе возвращает `403 Forbidden`.
 

 
## Фронтенд
 
React-приложение (Vite).
 
Позволяет управлять:
 
- **Товарами** — просматривать список с карточками и изображениями, открывать детальную страницу, создавать, редактировать и удалять товары (в зависимости от роли)
- **Пользователями** — администратор видит вкладку «Пользователи», где может изменять данные и роль любого пользователя, а также блокировать аккаунты
